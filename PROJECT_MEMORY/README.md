# WeTravellers Project Memory System

## Which file should I give an AI?

### ChatGPT / Claude / analytical model
Give:
`01_MASTER_MEMORY.md`

Optionally also give:
`03_CURRENT_STATE.md`

### DeepSeek / Cline / Qwen / execution agent
Give:
`02_AGENT_MEMORY.md`
+
`03_CURRENT_STATE.md`
+
the execution prompt generated by the analytical model.

### Quick handoff
Give:
`09_AI_HANDOFF.md`
+
`03_CURRENT_STATE.md`

## Source of truth
`01_MASTER_MEMORY.md` is the human/AI master context.
Git history is the authoritative code-change history.
`03_CURRENT_STATE.md` is the current checkpoint.
`10_DEEPSEEK_CONTEXT.md` is the compact execution context.

## Update policy
Do not let different files become competing sources of truth. Update the master memory after meaningful architectural/phase changes, then refresh the derived context files.

## Safety
The memory system must never contain API keys, passwords, tokens, or other secrets.
